03

Læg FFF på din telefon

Gør det først

iPhone og iPad — i Safari

  1. Tryk på Del-knappen
  2. Vælg “Føj til hjemmeskærm”
  3. Åbn FFF fra hjemmeskærmen

Android — i Chrome

  1. Tryk på menuen ⋮
  2. Vælg “Installer app”
  3. Bekræft — ikonet lægger sig på startskærmen

Så: notifikationer

  1. Din profil → Slå notifikationer til
  2. Sig Tillad
  3. Send en testnotifikation
Husk På iPhone skal appen ligge på hjemmeskærmen, før notifikationer kan slås til. Du får besked om beskeder, afstemninger og begivenheder i chatten — og det slås til pr. enhed.

Kalenderen i din egen kalender

  • Din profil → Kalender på din telefon → Aktivér
  • iPhone: tryk “Åbn i kalender-app”
  • Android: kopiér linket ind på calendar.google.com
  • Begivenhederne opdaterer sig selv
  • Linket er personligt — del det ikke

Kom i gang

  1. Log ind på fffloge.dk
  2. Skift adgangskode
  3. Læg FFF på hjemmeskærmen
  4. Slå notifikationer til
  5. Meld til bowling 🎳
